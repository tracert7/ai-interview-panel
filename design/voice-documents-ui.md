# 서류를 들고 들어오는 픽셀 면접실

## 방향

GitHub `anthropics/skills/skills/frontend-design`를 설치하고 전체 지침을 읽었다.
UI/UX Pro Max의 pixel-art 검색 결과도 참고했다. 기존 사용자가 고른 면접실
그림과 세 면접관을 중심으로 남긴다. 영문 장식 라벨, 모든 기능이 펼쳐진
긴 설정 화면은 줄이고 준비/면접/피드백의 실제 순서만 드러낸다.

- 밤색 바탕 `#20242f`, 깊은 책상 `#283448`, 종이 `#f7f1e7`, 잉크 `#172033`,
  선택 파랑 `#b9d1ff`, 녹음 표시 `#ffb8b4`.
- 한국어는 시스템 한글 글꼴을 15~16px로 읽는다. 장식용 픽셀 폰트는 쓰지 않는다.
- 넓은 화면은 면접실 왼쪽 / 대화·답변 오른쪽. 준비 서류는 접이식 서류철,
  연결 계정도 접어서 면접 자체를 먼저 본다. 작은 화면은 세로로 흐른다.

```text
제목                           준비 / 질문 / 답변 / 피드백
[구독 연결·모델 선택: 접이식]
[지원 공고·경험·서류: 접이식] → 읽은 내용 확인 → 서류로 질문 받기
┌─ 픽셀 면접실 ──────┬─ 세 면접관 ──────────┐
│   세 면접관        │  질문 + 서류 인용 근거 │
│       나           │  답변                 │
│                   │  [말로 답하기][정지]   │
└───────────────────┴─ [세 관점 평가] ───────┘
[면접 피드백 노트: 결과가 있을 때 펼침]
```

## 동작과 안전

- 파일 선택은 로컬 서버에만 전달해 메모리에서 텍스트로 읽는다. 저장하지 않는다.
  PDF/TXT/MD/DOCX, 1개 5MiB, 최대 3개, 합계 18,000자. 긴 문서는 몰래 자르지 않는다.
  PDF는 최대 30쪽. 스캔·암호 문서는 오류와 대체 방법을 보여 준다.
- 선택 직후 미리보기에서 개인정보와 인식 누락을 수정하거나 지운다.
  OpenAI 전송은 동의 후 질문 생성/평가 버튼에서만 한다. 문서 지시는 데이터다.
- 서류 질문은 역할별 1개와 원문 인용을 반환한다. 인용이 실제 전달 문서에
  없으면 실패 처리한다. 질문 선택은 사용량을 쓰지 않는다.
- 마이크는 클릭 전에는 시작하지 않는다. 브라우저 음성 인식 서비스의
  음성 전송 가능성을 알리고 별도 동의를 받는다. 인식 문장은 직접 고친 뒤
  제출한다. 중간 인식은 미리보기, 확정 문장만 답변에 추가한다.
- 음성 미지원/권한 거부/네트워크 오류에서 키보드 입력을 유지한다.
  다른 모드·전송·페이지 숨김 때 자동 녹음을 중단하고 자동 재시작하지 않는다.
- 음색·표정·억양 평가는 하지 않는다. 별도 유료 음성 API로 전환하지 않는다.

## 검수

375/768/1440px 렌더, 키보드 포커스, 긴 파일명·오류·생성 중·미지원 상태,
중복 인식 방지·권한 거부·첨부 삭제·원문 인용 대조·구독 실제 1회 요청을 확인한다.
브라우저 자동 제어 또는 실제 마이크 접근이 불가하면 미검증으로 기록한다.
