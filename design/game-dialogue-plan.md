# 말하는 면접관 · 2026-10-19

사용자는 정적인 방 그림+아래 자막이 아니라 캐릭터 머리 위 말풍선과 게임식
반응을 요청했다. 기존 세 사람의 정체성과 방을 유지하면서 인물 없는 배경과
세 캐릭터의 별도 대화 동작 스프라이트를 내장 image_gen으로 제작한다.

- 기존 픽셀 방/입장형/마이크/서류/구독 연결/등급은 유지한다.
- 질문 말풍선은 방 아래에서 캐릭터 위로 이동한다. 말하는 면접관에게 꼬리가
  향하고, 캐릭터 선택 시 해당 역할의 질문·피드백으로 바뀐다.
- 눈 깜빡임/말하기/고민·메모/완료 반응은 대화 동작 한 계열의 6프레임 자산.
  짙은 외곽선·작은 픽셀·차분한 정장 색을 기존 방에 맞춘다.
- 호출 중인 역할만 고민 동작과 …를 보인다. 실제 역할 결과가 도착하면
  완료 반응, 실패하면 확인 필요로 바뀐다. 역할끼리 실제로 토론하거나
  내부 추론을 읽어 보여주는 기능이 아님을 설명한다. 고정 대기 시간을
  삽입하거나 가짜 의견·점수·진행률을 만들지 않는다.
- 완료 후 장면에 남아 반응을 볼 수 있고 ‘종합 등급 보기’로 결과에 이동한다.
- 로딩 연출·캐릭터 효과는 화면 표시용이며 추가 모델 호출·과금은 없다.
- 모션 감소 설정과 화면의 애니메이션 끄기, 명확한 오류/중단 상태, 한글
  16px 이상 질문, 모바일 말풍선 레이아웃을 검수한다.

자산 프롬프트와 원본/분할/QC 메타데이터는 작업 팩에 보관한다. 참고 이미지에
포함된 브라우저 북마크·계정 등은 자산이나 공개 문서에 옮기지 않는다.
