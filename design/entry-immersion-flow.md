# 입장형에서 몰입형으로 · 2026-10-18

사용자가 시안 중 추천된 조합을 선택했다. frontend-design의 제품 중심 구성과
UI/UX Pro Max의 단계별 정보 노출을 참고하되, 검색의 VR·유리 효과 권고는
면접 연습에 맞지 않아 적용하지 않았다.

- 준비: 흰 종이 `#ffffff`, 잉크 `#172638`, 파랑 CTA `#264fd6`.
  왼쪽은 픽셀 면접실 그림, 오른쪽은 직무·선택 첨부·동의·시작 버튼.
- 면접: 밤색 `#172536`, 보조 면 `#283c54`, 따뜻한 CTA `#f0c785`.
  면접실을 크게 보여주고 하단에 질문을 얹는다. 시작 전에는 말로 답변,
  발화 중에는 답변 마치기, 수정 후에는 평가가 주 행동이 된다.
- 한글 시스템 글꼴, 본문 15px, 질문 22~31px. 장식용 영문 라벨을 줄인다.
- 계정·모델은 상단 모달, 경험·수동 질문과 서류 질문 미리보기는 접이식.
- Work 요청문 메뉴·클립보드 복사·TXT 다운로드·사용하지 않는 생성 함수를 제거한다.
  과거 실습 예제의 출처와 검증 기록은 보존한다.
- 첨부 읽기는 계속 로컬에서만 수행한다. 시작은 사전 동의 후 서류 질문
  한 번을 생성하고 첫 질문으로 입장한다. 실패하면 준비 화면에 남긴다.
  마이크·평가는 자동으로 시작하지 않는다. API 키 fallback도 추가하지 않는다.
- 돌아가기는 서류·답변·기록을 지우지 않는다. 예제 전환은 실습 입력을
  별도 탭 메모리에 보관했다가 내 면접으로 돌아올 때 복원한다.

검수: DOM 흐름·실패·동의·왕복·예제 복원을 자동 시험한다. 실제 렌더는
브라우저 연결이 복구되면 375/768/1440px에서 확인하며 미확인은 미확인으로 남긴다.
