# AI 모의면접실 · 내 ChatGPT 구독으로 연습하기

**GitHub에서 받기 → PC에서 실행 → ChatGPT로 로그인 → 내 구독으로 면접 진행**

픽셀 면접실에서 질문에 답하면 인사담당자·현업·팀장 관점의 피드백을 따로 받습니다. 별도 OpenAI API 키를 넣거나 API 결제를 설정하지 않습니다. 지원 대상 ChatGPT 계정의 사용 권한이 필요하며, 면접 연습은 기존 구독 사용량을 소모합니다.

**[다운로드 ZIP](https://github.com/tracert7/ai-interview-panel/archive/refs/heads/main.zip)** · [화면 예제 보기](https://tracert7.github.io/ai-interview-panel/) · [검증 기록](docs/verification.md)

첫 화면에서 직무·서류를 준비하고 **면접 시작하기**를 누르면 면접실을 크게 보여주는 몰입 화면으로 넘어갑니다. 연결 설정은 상단 **ChatGPT 연결·설정**에서 열며, 면접 중에는 질문·답변에 집중합니다.

## 시작하기

Windows 기준입니다. Node.js 22.13 이상이 필요합니다. 없으면 [Node.js 공식 사이트](https://nodejs.org/)에서 LTS 버전을 먼저 설치하세요.

1. 위 **다운로드 ZIP**을 받아 압축을 풉니다. ZIP 안에서 바로 실행하지 않습니다.
2. 압축을 푼 폴더의 **START-WINDOWS.cmd**를 더블클릭합니다. 첫 실행에는 고정된 로그인·서류 읽기 의존성을 설치합니다. 이전 버전을 쓰던 중이라면 실행 창을 닫고 새 파일로 업데이트한 뒤 다시 실행합니다.
3. 자동으로 열린 **http://127.0.0.1:4317/** 에서 준비할 직무를 입력합니다. 상단 **ChatGPT 연결·설정**을 열고 **Continue with ChatGPT**를 누릅니다. 연결이 필요하면 **면접 시작하기**에서도 이 설정 창을 엽니다.
4. OpenAI 공식 로그인 화면에서 본인 계정으로 로그인하고, 이 앱의 ChatGPT 구독 사용 권한을 확인합니다. 비밀번호나 API 키를 면접실에 입력하지 않습니다.
5. 설정의 **사용할 모델**에서 계정에 제공되는 모델을 고르고 **설정 마치기**를 누릅니다. 로그인만 허용하고 구독 사용은 허용하지 않았다면 평가할 수 없습니다.
6. **경험·공고를 더 자세히 적기**에서 본인이 실제로 한 일을 추가할 수 있습니다. 초기 화면에는 가상 지원자의 내용을 대신 채워 넣지 않습니다. 이름·연락처·민감정보·회사 비공개 자료는 넣지 않습니다.
7. **서류 첨부**로 자소서·이력서·회사 제출 서류를 선택합니다. 파일명을 눌러 읽힌 내용을 확인하고 개인정보를 지웁니다. 전송 동의 후 **면접 시작하기**를 누르면 서류 질문을 준비하고 인사담당자의 첫 질문으로 몰입 면접실에 들어갑니다. 질문을 직접 고르고 싶으면 보조 메뉴 **서류 질문 미리 고르기 → 질문 미리보기**를 사용합니다. 첨부가 없으면 기본 질문 또는 직접 설정한 질문으로 시작하며 이때 AI 질문 생성 요청은 없습니다.
8. **말로 답변 시작**을 누르고 마이크 안내에 동의하면 한국어 음성이 답변 칸에 추가됩니다. **답변 마치기** 뒤 **답변 확인·직접 입력**에서 오인식된 이름·숫자·전문 용어를 고칩니다. **키보드로 답하기**도 가능합니다. **이 답변 평가받기**를 눌러야 AI에 답변을 보냅니다.
9. 세 평가가 끝나면 **면접 피드백 노트**를 읽습니다. 면접관을 선택하면 해당 관점의 꼬리질문이 말풍선에 표시됩니다. 고칠 점 하나를 반영해 다시 답하거나 다음 질문으로 이어갑니다.

실행 창은 면접실을 사용하는 동안 열어 둡니다. 종료는 그 창에서 Ctrl+C를 누르면 됩니다. 한 PC에서는 같은 폴더의 면접실을 한 번만 실행하세요.

직접 실행하거나 macOS/Linux에서 실행할 때:

```sh
npm ci --omit=dev --omit=optional --ignore-scripts
npm start
```

표시된 **127.0.0.1 주소**를 브라우저에서 엽니다. macOS/Linux에서는 토큰을 디스크에 저장하지 않으므로 서버를 다시 시작하면 다시 로그인해야 합니다. 계정 등록 식별 정보와 호스트 ID는 보호된 로컬 폴더에 남겨 같은 앱 등록을 재사용합니다.

## 비용과 한도

- 별도 API 키나 API 과금 계정으로 자동 전환하는 경로는 없습니다. 환경변수에 API 키가 있더라도 이 앱이 가져다 쓰지 않습니다.
- 답변 하나당 역할별 요청 세 개가 기존 ChatGPT 사용량을 소모합니다. 무제한 무료라는 뜻이 아닙니다.
- 서류 기반 질문 세 개를 준비할 때는 별도 요청 한 번을 사용합니다. 질문 선택과 PC 안에서 서류를 읽는 작업은 AI를 호출하지 않습니다.
- 구독 사용 한도·권한·모델 오류가 나면 실패를 표시합니다. 자동 재시도하거나 다른 결제 방식으로 우회하지 않습니다.
- 추가 크레딧도 사용하고 싶지 않다면 **ChatGPT 설정의 이 앱 사용량·크레딧 허용**을 직접 확인하세요. 사용자가 이미 허용한 크레딧 사용 여부를 이 앱이 임의로 바꾸지 않으며, 크레딧을 구매하지도 않습니다.
- 전체 평가의 대기 제한은 90초입니다. 취소해도 이미 소모한 사용량은 되돌릴 수 없습니다. 구독 연결의 현재 지원 제약 때문에 출력 토큰의 강제 상한을 요청에 넣지는 않습니다.

[OpenAI 구독 연결 안내](https://developers.openai.com/siwc/token-sharing-open-source)와 [현재 제약](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)을 확인하세요. 지원 계정과 모델은 실제 로그인 후 받은 권한·목록으로 확인합니다.

## 세 면접관은 어떻게 평가하나요?

인사담당자는 지원 이유와 일관성, 현업은 근거와 문제 해결, 팀장은 본인 역할과 협업 책임을 봅니다. 같은 공고·경험·질문·답변을 각자 다른 역할 지침과 함께 **별도 모델 요청 세 개**로 병렬 평가합니다. 다른 역할의 점수나 피드백은 서로 전달하지 않습니다.

이 로컬 앱은 서로 다른 기반 모델이나 통계적으로 독립적인 사람 면접관 세 명을 검증하는 서비스가 아닙니다. 앱 안의 독립된 역할별 모델 요청을 사용하며, 다른 화면에 요청문을 복사하는 기능은 제거했습니다. 과거 실제 실습의 기록만 예제로 남겼습니다.

평가 기준은 질문 적합성 / 본인 행동 / 구체적인 근거 / 전달 구조 / 사실 일관성, 각 0~4점입니다. 합계는 코드로 계산하며 20점 만점입니다. 답변에 없는 인용이나 잘못된 점수 형식은 표시하지 않습니다. 점수를 합격률·채용 순위·실력 향상률로 바꾸지 않습니다.

픽셀 캐릭터는 역할 안내용 그림입니다. 음성 입력은 말한 내용을 글자로 바꾸는 기능이며, 표정·시선·목소리·억양을 평가하지 않습니다. 세 역할의 평가는 수정 가능한 답변 텍스트를 제출한 뒤 시작합니다.

## 자소서·회사 제출 서류 첨부

- **PDF, DOCX, UTF-8 TXT, MD**: 최대 3개, 파일당 5MiB, 본문 합계 18,000자. PDF는 30쪽까지입니다. 긴 문서를 몰래 잘라 보내지 않고 필요한 부분만 남기도록 안내합니다.
- **파일 선택만으로 OpenAI에 보내지 않습니다.** 본인 PC의 로컬 서버가 메모리에서 텍스트를 읽어 미리보기에 돌려줍니다. 파일 원본·본문을 디스크에 저장하지 않습니다.
- 파일명을 눌러 미리보기를 펼치고, 연락처·이름·식별번호·민감정보·회사 비공개 내용은 지우세요. 미리보기 본문은 직접 수정하거나 첨부별로 삭제할 수 있습니다.
- 전송 동의 후 서류가 있는 상태에서 **면접 시작하기**, 보조 메뉴의 **질문 미리보기**, 또는 **이 답변 평가받기**를 누르면 **현재 첨부의 읽힌 본문 전체**가 공고·경험과 함께 OpenAI로 전송됩니다. 한 번 동의하더라도 첨부를 추가·수정하거나 공고·경험을 바꾸면 다시 확인합니다.
- 생성된 질문에는 해당 서류의 실제 원문 인용이 필요합니다. 서버에서 파일명·인용 일치를 대조하며, 인용이 없거나 다른 원문이면 표시하지 않습니다. 인용 일치가 질문의 품질·편향 없음·사실 진실성을 보장하는 것은 아닙니다.
- 스캔 PDF·이미지의 글자는 OCR하지 않습니다. HWP·옛 DOC는 지원하지 않으므로 텍스트 PDF 또는 TXT로 변환하세요. 암호 PDF도 잠금을 해제한 사본이나 TXT로 준비합니다.
- PDF의 표·다단 편집은 읽기 순서가 달라질 수 있습니다. DOCX는 본문 XML의 텍스트를 읽으며 머리말·꼬리말·그림·댓글은 포함하지 않습니다. 미리보기와 원본을 대조하세요.
- 새로고침·로그인 이동 시 첨부는 사라집니다. 삭제해도 이미 OpenAI로 전송한 내용을 회수하는 기능은 아닙니다. 기록 내보내기에는 당시 첨부 본문도 포함됩니다.

## 마이크로 답변하기

브라우저의 [SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)을 사용합니다. 지원 여부는 화면에서 확인하며 Chrome 사용을 권합니다. 마이크 권한·인터넷·브라우저 정책에 따라 사용할 수 없을 수 있습니다. 미지원·권한 거부·연결 오류에서는 키보드 입력을 계속할 수 있습니다.

**말로 답변 시작**을 누르기 전에는 마이크를 열지 않습니다. 음성 처리 안내에 동의한 뒤 시작하면, 확정된 문장만 기존 답변 뒤에 붙이고 인식 중인 문장은 별도로 보여줍니다. 자동 제출·자동 재시작하지 않으며 정지·준비 화면으로 돌아가기·다른 탭으로 이동할 때 듣기를 멈춥니다.

일부 브라우저는 음성을 제공업체 서버로 전송해 인식합니다. 완전한 오프라인·PC 내부 처리라고 보장하지 않습니다. 이 앱은 녹음 파일을 보관하지 않으며 유료 OpenAI 전사 API로 전환하지 않습니다. OpenAI로 보내는 것은 확인 후 제출한 텍스트입니다.

## 개인정보와 로그인 보관

- 비밀번호는 OpenAI 로그인 화면에서만 입력합니다. 이 앱은 기존 ChatGPT·Codex의 로그인 파일을 읽거나 복사하지 않습니다.
- 새 로그인에서 받은 토큰은 서버 내부에서만 사용합니다. 브라우저 저장소·화면·로그·GitHub로 보내지 않습니다.
- Windows에서는 현재 사용자 계정의 DPAPI로 암호화해 앱 폴더의 **.private/** 에 보관합니다. 이 폴더는 Git과 웹 제공 경로에서 제외됩니다. 다른 PC에 복사해 쓰지 마세요.
- macOS/Linux에서는 토큰을 메모리에만 두고, 계정 등록 메타데이터만 소유자 전용 파일에 보관합니다.
- **연결 종료**는 원격 세션 취소를 시도한 뒤 이 PC의 토큰을 지웁니다. 원격 취소를 확인하지 못하면 화면에 알리므로 ChatGPT 설정에서도 앱 연결을 확인하세요.
- 공고·경험·답변·평가 기록은 기본적으로 탭 메모리에만 둡니다. 로그인 중에는 입력을 잃지 않도록 로컬 서버 메모리에 최대 5분 임시 보관하고, 돌아온 탭에서 한 번 가져오면 지웁니다.
- 첨부는 읽는 동안 로컬 서버 메모리를 거치고 미리보기는 탭 메모리에 둡니다. 로그인용 임시 입력에는 첨부를 보관하지 않습니다. 서버에 문서 업로드 보관함을 만들지 않습니다.
- **기록 내보내기** 파일에는 본인 경험과 답변이 포함됩니다. GitHub나 공개 게시판에 올리지 마세요.
- 서버는 127.0.0.1에만 연결합니다. 공용 네트워크에 노출하거나 포트 포워딩하지 마세요.

## 화면만 먼저 보고 싶다면

[웹 예제](https://tracert7.github.io/ai-interview-panel/)의 입장 화면에서 **기록된 예제 둘러보기**를 누릅니다. 가상 첫 답변이 들어 있는 몰입 면접실로 이동하며, **기록된 평가 펼치기**로 과거 실습 결과를 읽을 수 있습니다. 새 AI 평가나 음성 인식을 자동 실행하지 않습니다. **내 면접 준비**로 돌아오면 기존에 적어 둔 직무·경험·답변을 복원합니다.

## 문제가 생겼다면

|화면|확인할 것|
|---|---|
|로그인 전|PC 실행판인지 확인하고 Continue with ChatGPT를 누릅니다.|
|로그인했지만 구독 권한 없음|OpenAI에서 앱의 구독 사용을 허용했는지 확인하고 다시 연결합니다.|
|모델이 없음|계정·구독·워크스페이스의 지원 조건을 확인합니다. 임의의 모델 ID를 넣지 않습니다.|
|한도·권한 오류|ChatGPT의 앱 사용량·권한을 확인합니다. API 키를 넣어 우회하지 않습니다.|
|이중 실행·저장소 오류|다른 실행 창을 먼저 닫습니다. .private의 암호화 파일을 임의로 지우거나 다른 PC 파일로 덮지 않습니다.|
|동의 취소·로그인 중단|앱의 ‘진행 중인 로그인 취소’를 누른 뒤 다시 시작합니다.|
|창이 안 열림|실행 창에 나온 127.0.0.1 주소를 Chrome에서 직접 엽니다.|
|START가 곧바로 종료됨|Node.js 22.13 이상 설치와 압축 해제를 확인합니다.|
|말로 답변 시작이 비활성|음성 인식 미지원 브라우저이거나 예제 보기 상태입니다. Chrome에서 내 면접을 시작하거나 키보드로 입력하세요.|
|마이크 권한 거부·음성 인식 실패|주소창 사이트 설정의 마이크 권한, 장치, 인터넷 연결을 확인하세요. 자동 재시작하지 않으므로 다시 시작 버튼을 누릅니다.|
|서류 읽기 실패|스캔·암호·HWP·파일 손상·크기 제한을 확인하세요. 필요한 부분을 UTF-8 TXT로 저장하면 됩니다.|
|질문을 만들 내용 부족|서류에 직무 관련 행동·프로젝트 내용이 있는지 확인하세요. 개인정보만 있는 서류는 사용하지 않습니다.|

UI 개선에는 GitHub의 [frontend-design 스킬](https://github.com/anthropics/skills/tree/main/skills/frontend-design)을 참고했고 기존 픽셀 면접실의 방향은 유지했습니다.

[검증 기록](docs/verification.md)에 실제 계정과 모의 전송 테스트를 구분해 남깁니다. 테스트 통과만으로 모든 계정에서 로그인이나 면접 결과가 같다고 주장하지 않습니다.
